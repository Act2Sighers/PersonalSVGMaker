# Personal SVG Maker

ゲーム素材（キャラクター、アイコン、UIパーツなど）用の SVG を描くための、ブラウザで動く作図ツールです。
iPad を指で操作する前提で作っています。

## 使い方（段階1の機能）

### 基本操作
| 操作 | 内容 |
|---|---|
| ペン／ハンド（上部バー） | ペン = 1本指で描画・選択、ハンド = 1本指でキャンバスを移動 |
| 2本指でドラッグ／ピンチ／ひねる | キャンバスの移動・ズーム・回転。2本の指の位置に合わせて動きます（ペン状態でも使えます）。回転は 0°・90°・180°・270° の近くで吸い付き、「全体表示」で元の向きに戻ります |
| 2本指タップ | 作図中なら最後の点を1つ取り消す（残り1点なら作図をやめる）。作図中でなければ元に戻す |
| 3本指タップ | やり直し |

点は **指を離した位置で確定** します。指を置いたまま動かすとスナップ先が表示され、指の上にルーペが出ます。

### ツール
- **選択**：線をタップで図形ごと選択、点をタップで1点だけ選択、空白をなぞると範囲選択。「追加選択」をオンにすると選択を足したり外したりできます。
  - 選択できるのは、レイヤー一覧で選んでいるレイヤーの図形だけです。レイヤーを切り替えると選択は解除されます。
  - グループ化／グループ解除：2つ以上の図形をまとめます。グループの図形は、線や点のどこを選んでもグループ全体が選ばれます。1つだけ動かしたいときは、グループを解除してください。グループは入れ子にしません。既にあるグループを含めてグループ化すると、古いグループは新しいグループに置き換わります（解除しても古いグループには戻りません）。既にあるグループとまったく同じ図形の組み合わせでは、グループ化は押せません。
  - コピー／貼り付け／複製：配置を保ったまま複製します。貼り付けでは「基準点」→「置く位置」を指定します。その図形だけで囲まれた範囲の塗りも一緒に複製されます。
- **移動**：「コピーして移動」をオンにすると、元を残して複製を置きます。CAD と同じ手順です。「基準点」→「移動先」の順にタップします。一部の点だけを選んでいれば、その点だけが動くので図形をストレッチできます。移動先は、動かしている図形自身の端点や交点（移動前の位置）にも吸着します。
- **変形**：選択した点や図形を変形します。「コピーを作る」をオンにすると、元を残して変形した複製を作ります。
  - 拡大縮小／回転：「基準点」→「参照点」→「参照点の行き先」の順にタップします。基準点を決めたあとは、倍率（%）や角度（°）を数値で指定することもできます。回転には15°刻みの設定があります。基準点は変形のあとも残るので、同じ中心で続けて回転コピーができます。
  - 反転：基準点（指定しなければ選択の中心）を通る軸で左右・上下に反転するか、2点で軸を指定します。
  - 全体を選んだ図形の塗りは、グラデーションも含めて一緒に変形されます。
- **直線**：タップした点を順につなぎます。最後の点をもう一度タップすると完了、始点をタップすると閉じた図形になります。「1本ずつ」をオンにすると、2点ごとに1本の線として確定します。
- **曲線**：作り方を2種類から選べます。
  - ハンドル：タップで頂点を置き、置いたばかりの頂点から指をなぞると曲線のハンドルを引き出せます。
  - 3点を通る：始点 → 通過点 → 終点 の順にタップすると、3点を通る滑らかな曲線になります。通過点は頂点として残るので、後から動かせます。
- **円**：作り方を3種類から選べます。
  - 中心と半径：1点目が中心、2点目までの距離が半径になります。
  - 直径（2点）：1点目と2点目が直径の両端になります。
  - 3点を通る：3点すべてを通る円になります。

  「多角形」に切り替えると正多角形になり、辺の数を変えられます（中心以外で最初に置いた点が頂点の1つになります）。円で掴める点は中心だけです。

- **手描き**：指でなぞった一筆書きの線を、直線・曲線・円に置き換えます。
  - 角で区切る：はっきりした角で線を区切り、区切った部分ごとに直線・曲線・円のどれかを選びます。角は、狭い幅でも広い幅でもほぼ同じだけ曲がっている所として判定するので、急なカーブは角になりにくくなっています。円になるのは、区切った部分だけで一周して閉じていて、点の並びが円に十分近いときだけです。
  - 等間隔：線を同じくらいの長さに等分し、それぞれを直線か曲線にします（円にはなりません）。区切りの長さは「粗い・普通・細かい」から選べます（画面上でおよそ 130・80・45px）。つなぎ目は滑らかにつながります。
  - 線の両端の「はね」（指を置いた直後や離す直前にできる小さなかぎ）は、取り除いてから変換します。
  - 始点と終点は、既存の端点・交点・接点・線上に吸着します。端だけを動かすと折れ目ができるので、端から少し手前までなだらかに寄せます。始点の近くで描き終えると閉じた図形になります。
  - 変換した結果に極端に短い区間ができそうなときは、隣の区間とまとめて変換し直します。
  - 途中で既存の点や交点のすぐ近くを通ると、そこを必ず通る頂点になります。まっすぐ描いた部分は、まっすぐなままその点を通ります。
- **塗り**：線で閉じた範囲をタップすると塗りつぶします。
  - 単色：選んだ色で塗ります。色は不透明度（%）込みで選びます。同じ色でも不透明度が違えば別の色として扱い、塗ると前の色を上書きします。最近使った色はパレットに並びます（半透明の色は市松模様の上に表示）。
  - グラデーション：範囲をタップ → 始点 → 終点 の順にタップすると、2色の直線的なグラデーションになります。始点と終点にも吸着が効きます。
  - スポイト：塗りをタップすると、その色を取り込みます。
  - 塗りを消す：タップした範囲の塗りを消します。
  - 「線を表示」をオフにすると、塗りだけの仕上がりを確認できます。

### 塗りの仕組み
線は色を持たず、塗りの範囲を決めるためだけに使います。範囲は線から毎回計算し直すので、点や図形を動かすと塗りも追従します。
- 移動・変形：同じ線で囲まれた範囲として、塗りがそのままついていきます。グラデーションも一緒に動きます。
- 分割：塗った範囲を線で区切ると、分かれた範囲それぞれに同じ塗りが残ります。
- 区切りがなくなって範囲がつながった：つながった範囲の中で、いちばん広い部分を占めていた色で塗り直します（塗られていない部分が多ければ塗りません）。
- 範囲が開いた：その範囲の色は消えます。閉じ直しても色は戻らないので、塗り直すか「元に戻す」を使ってください。

### 書き出し
上部バーの「書き出し」から、塗りだけの SVG を書き出せます。線は範囲を決めるためのものなので含まれません。
- SVGファイルを保存
- SVGのコードをコピー：ゲーム側の Claude Code にそのまま貼り付けて渡せます。
- 隣り合う塗りの境目に、背景が細く透けて見えないようにする設定があります（塗りと同じ色の縁を 0.5 だけ付けます）。

### レイヤー
上部バーの「レイヤー」で一覧を開きます。一覧の上にあるものほど手前に表示されます。
- レイヤーとフォルダーを作れます。フォルダーは入れ子にでき、フォルダーの表示・ロックは中身すべてに効きます。
- 一覧で選んだレイヤーに新しい図形が描かれ、塗りもそのレイヤーの線で決まります。
- 表示（目のアイコン）とロック（鍵のアイコン）を切り替えられます。
- 「不透明度（選んでいる項目）」で、レイヤー・フォルダーごとの不透明度を決められます。半透明のフォルダーは、中身をまとめて描いてから薄くするので、中で重なった所が二重に透けません（書き出した SVG の `<g opacity>` と同じ見え方です）。
- ↑↓で並べ替え、「上のフォルダーへ入れる」「フォルダーから出す」でフォルダーに出し入れします。
- 「選択を別のレイヤーへ」：押してから移し先のレイヤーをタップすると、選択中の図形をそのレイヤーへ移します。塗りも一緒に移ります。
- 書き出しの SVG では、フォルダーとレイヤーがそれぞれ `<g>` になります（`data-name` に名前が入ります）。

### 線の生成
レイヤー一覧で線のあるレイヤーを選び、「線を生成」を押すと、その線を太さのある色付きの線に置き換えたレイヤーを、すぐ上に作ります（元のレイヤーはそのまま残ります）。
- 太さ、角と端の処理、色（不透明度込み）を選びます。
  - 丸み：端は半円、角は丸く。
  - シャープ：端は直角に切り落とし、角は元の線が交わる角度のままとがらせます。とがった先が太さの4倍より長くなる所は、平らに切り落とします。
- 曲線や円にも使えます。円はドーナツ形に、閉じた図形は外側と内側の2本の輪郭になります。
- 別々に描いた線でも、端どうしが重なっていればひと続きの線として扱い、つなぎ目を角として処理します（「一点ずつ」で描いた四角形も、続けて描いた四角形と同じ仕上がりになります）。3本以上の線の端が集まる所はつなぎません。
- 作られるのは、線の輪郭（ベクター線）と、その内側の塗りです。線が交わる所や角の内側で輪郭が重なっても、塗りは1本の太い線として見えます。
- 生成は1回きりです。元の線を直しても生成した線は変わらないので、必要なら生成し直してください。

### 下書き画像
設定パネルの「下書き画像」で、PNG・JPEG などの画像を下書きとして読み込めます（何枚でも）。
- 表示・非表示、不透明度、位置（なぞって動かす・大きさを変える・キャンバスに合わせる）を変えられます。
- 下書きは表示用で、SVG の書き出しには含まれません。作品ファイル（`.svgmaker.json`）には画像も含まれます。
- 大きな画像は、保存するときに長辺 2048px まで縮めます。

### ミラー描画
設定パネルで、縦の軸（左右対称）または横の軸（上下対称）を選びます。直線・曲線・円で描いた図形が、軸で折り返した位置にも作られます。描いている間は、反対側にも薄く表示されます。軸の位置は数値でもタップでも指定できます。

### アニメーション
上部バーの「アニメ」で、アニメーションの編集に切り替えます（もう一度押すと形の編集に戻ります）。アニメーション中は形を変えられません。形を直すときはアニメを終えてください。

- **パーツ**：レイヤーとフォルダーが、そのまま動かせるパーツになります。フォルダーの動きは中のパーツにも及ぶので、「腕」フォルダーの中に「手」を入れれば、肩を回すと手もついてきます（ボーンの代わり）。
- **パーツを選ぶ**：キャンバスでタップするとそのレイヤーが選ばれます。「親のフォルダーを選ぶ」やレイヤー一覧で、フォルダーごと選ぶこともできます。
- **中心点を置く**：回転・拡大縮小の中心をタップで置きます。置いている間は、描いたままの状態で表示します。置かなければ、パーツの中身の中央が中心になります。
- **動かす**：「回転」「移動」「拡大縮小（縦横・横だけ・縦だけ）」を選び、キャンバスをなぞります。指を離すと、今の時刻にキーが打たれます。
- **不透明度**：数値を入れて「不透明度のキー」で打ちます。アニメーションの不透明度は、レイヤー・フォルダーの不透明度の上からさらに掛け合わせます（50% のレイヤーに 50% を掛けると 25%）。塗りごとの不透明度の違いはそのまま保たれます。
- **タイムライン**（画面下）
  - クリップ：「待機」などの動きのまとまりです。作品ごとに複数作れます。長さ（秒）とループを決められます。
  - 再生・停止、つまみで時刻を移動、列の空いた所をタップしてその時刻へ移動。
  - 菱形がキーです。タップすると、値の変更、次のキーまでのつなぎ方の切り替え、削除ができます。
  - つなぎ方：等速／瞬時（区間に入った瞬間に次の値になり、あとは動かない）／加速→減速（中点で切り替え）／加速／減速／円・加速／円・減速。加速・減速・加速→減速は、鋭さを「弱・中・強・最強」から選べます。
  - 下書き：「下書きを追加」で、今の時刻から次の下書きの時刻まで表示する画像を追加します。下書きの行の印をタップすると、不透明度・位置・時刻を変えたり削除したりできます。クリップに下書きがあるときは、作品の下書きの代わりにそちらを表示します。
  - 選んでいるパーツの、動きのある項目だけを表示します。ほかに動きのあるパーツは下にまとめて並び、名前をタップすると選べます。
- **揺れを付ける**：呼吸や髪の揺れのような小さな往復を、振れ幅・1往復の時間・タイミングのずれから自動で作ります。1往復の時間はクリップの長さで割り切れるように調整するので、ループしても途切れません。髪の房ごとにタイミングを少しずつずらすと自然になります。

#### ゲームへの受け渡し
「書き出し」の画面に、アニメーションがある作品だけ次のボタンが出ます。
- **ゲーム用にまとめてコピー**：再生のしかたの説明（計算式と参考コード付き）、パーツ SVG、アニメーション JSON をまとめた文章をコピーします。ゲーム側の Claude Code に貼り付けて「この説明に従って組み込んで」と頼めば使えます。
- **アニメーションJSONを保存**、**説明書を保存**

パーツ SVG では、パーツごとの `<g>` に `data-pivot-x`・`data-pivot-y`（中心点）が付きます。各パーツの変換は `translate(px + x, py + y) rotate(r) scale(sx, sy) translate(-px, -py)` で、入れ子の `<g>` に入れれば親の動きも合成されます。詳しくは書き出される説明を見てください。

### スナップ（吸着）
「吸着の対象」で、選んでいるレイヤーの図形だけに吸着するか、表示中のすべてのレイヤーの図形に吸着するかを切り替えられます。

次のものに吸着します。設定パネルでそれぞれオン／オフできます。
- 端点・中心
- 交点・接点：図形同士が交わる点と、円と円、円と直線などが接している点です。
- 垂線・接点：直前に置いた点から各線へ下ろした垂線の足です。円の場合は接点になります。たとえば円ツールで中心を置いたあと直線に近づけると、その直線に接する円が1手で描けます。
- 線上：直線、曲線、円の上の、指にいちばん近い点です。
- 延長線
- グリッド

### グリッド
設定パネルで、間隔、太線を引く間隔、基準点を変更できます。基準点はタップで指定することもできます。

### 作品の管理
作品はブラウザ内（IndexedDB）に自動保存されます。上部バーの「作品」で一覧を開きます。
- 作品はフォルダーに分けて整理できます。フォルダーの中にフォルダーも作れます。フォルダー名をタップすると中に入り、上の「すべての作品 › …」で戻れます。
- フォルダーは名前を変えられます。削除すると、中の作品とフォルダーは1つ上に移ります。
- 作品ごとに「移動」（別のフォルダーへ）、「複製」、「削除」ができます。新しい作品は、いま開いているフォルダーに作られます。
- 作品ファイル（`.svgmaker.json`）への保存と読み込み。線やレイヤー構成をすべて含むので、控えや別の端末への移動に使えます。

### SVG の取り込み
- 「SVGから新しい作品」：SVG ファイルを新しい作品として開きます。キャンバスの大きさは SVG の viewBox になります。
- 「SVGを読み込む」（編集中の作品）：今の作品の一番上に、フォルダーにまとめて読み込みます。
- 線になるもの：path・rect・circle・ellipse・line・polyline・polygon の輪郭。transform（回転・拡大縮小など）も反映します。
- 塗り：読み込んだ線でできた範囲ごとに、元の SVG でいちばん上に見えている色を付けます。重なった図形や、穴の空いた図形（evenodd）の見た目も再現されます。`<style>` の class 指定にも対応しています。線形グラデーションは最初と最後の色の2色に、放射グラデーションは中心の色の単色になります。
- `<g>` の入れ子は、フォルダーとレイヤーになります（`<g>` を含む `<g>` がフォルダー）。名前は `data-name`・Inkscape のレイヤー名・`id` から取ります。
- 読み込まないもの：線の太さ・線の色、文字、画像、`<use>`、スクリプトなど。読み込めなかったものは、読み込み後に一覧で知らせます。
- このツールで書き出した SVG は塗りだけなので、読み込むと塗りの輪郭が線になります。線もそのまま編集し直したいときは、作品ファイル（`.svgmaker.json`）を使ってください。

## 開発

```sh
npm install
npm run dev      # 開発サーバー（同じネットワークの iPad からも開けます）
npm run build    # dist/ に出力
```

`main` ブランチに push すると、GitHub Actions で GitHub Pages に公開されます。
初回だけ、リポジトリの Settings → Pages → Source を「GitHub Actions」にしてください。
